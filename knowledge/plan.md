# F1 賽車遊戲計畫

## 願景

打造一款打開瀏覽器就能玩的 F1 風格街機賽車遊戲，具有清楚的比賽資訊、易上手的鍵盤操控、可重玩的短賽事，並透過 GitHub Actions 自動發布到 GitHub Pages。

## 發布方式

推送到 `main` 分支會觸發 `.github/workflows/pages.yml`，透過 GitHub Pages artifact 部署靜態網站。首次發布需在 GitHub 專案設定中將 Pages Source 設為 **GitHub Actions**。
